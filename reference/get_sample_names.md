# Get sample names for a SCOUT SPN

Looks up sample names from the SCOUT metadata Google Sheet.

## Usage

``` r
get_sample_names(spn)
```

## Arguments

- spn:

  SPN identifier, e.g. `"SPN01"`.

## Value

Character vector of sample names.

## Examples

``` r
if (FALSE) { # \dontrun{
get_sample_names("SPN01")
} # }
```
