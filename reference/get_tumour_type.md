# Get tumour type for a SCOUT SPN

Looks up the tumour type from the SCOUT metadata Google Sheet.

## Usage

``` r
get_tumour_type(spn)
```

## Arguments

- spn:

  SPN identifier, e.g. `"SPN01"`.

## Value

A character string, e.g. `"CRC"`, `"AML"`.

## Examples

``` r
if (FALSE) { # \dontrun{
get_tumour_type("SPN01")
} # }
```
